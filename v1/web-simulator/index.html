TCP Tahoe (1988)

RFC 2001
Suitability: Poor
✔ Safe: Flushes congestion completely
✖ Sluggish: Slashing cwnd to 1 MSS destroys goodput
Best Condition: Extremely congested networks with high buffer contention where full link drainage is required.

TCP Reno (1990)

RFC 5681
Suitability: Moderate
✔ Fast Recovery: Halves cwnd on 3 Dup ACKs
✖ Stalls on multiple drops in single window
Best Condition: Low-delay LANs and wired links with single, isolated packet drop events.

TCP NewReno (1999)

RFC 6582
Suitability: High
✔ Partial ACKs: Handles multiple drops per window
✖ Linear AIMD (+1 MSS/RTT) still slow on high BDP
Best Condition: Bursty networks with multiple packet drops within a single round-trip time.

TCP Cubic (2008)

RFC 8312
Suitability: Optimal
✔ RTT-Independent: Cubic polynomial function
✔ Rapid recovery on Long Fat Networks (LFNs)
Best Condition: High-bandwidth, high-latency links (Internet, Satellite, 5G, and Cloud Data Centers).
