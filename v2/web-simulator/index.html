Core Networking Terminology Reference

Essential concepts and mathematical formulas you will encounter in the simulator.

cwnd (Congestion Window)
FlightSize ≤ min(cwnd, rwnd)

The maximum number of unacknowledged data bytes the sender can push into the network. Dynamically regulated to avoid bottleneck congestion.

ssthresh (Slow Start Threshold)
ssthresh = max(2, ⌊cwnd / 2⌋)

The dividing boundary between Slow Start (exponential growth: doubling every RTT) and Congestion Avoidance (linear AIMD: +1 MSS per RTT).

BDP (Bandwidth-Delay Product)
BDP = Bandwidth × Base RTT

The exact volume of data required to fill the physical transmission pipe. If cwnd < BDP, the bottleneck link is underutilized.

Goodput vs Throughput
Goodput = Payload Bits / Total Time

Throughput measures raw physical bits transmitted; Goodput measures only useful application payload delivered (excluding dropped retransmissions).

TCP Tahoe

Suitability: Poor

The original congestion control standard. Flushes network congestion safely, but causes severe throughput dips by dropping cwnd to 1 MSS on any loss.

TCP Reno

Suitability: Moderate

Introduced Fast Retransmit and Fast Recovery. Skips Slow Start on 3 duplicate ACKs, preserving packet clocking on low-delay links.

TCP NewReno

Suitability: High

Addresses Reno's inability to handle multiple packet losses in a single window by using Partial ACKs to trigger successive retransmissions.

TCP Cubic (Default)

Suitability: Optimal

Autonomous cubic polynomial window scaling independent of RTT. Recovers up to 2.5x faster than Reno on high-delay Long Fat Networks.
